읽는 것과 하는 것은 다르다. 이 영역은 앞 커리큘럼에서 배운 기법을 **인가된
실습 플랫폼**에서 직접 재현하도록 안내하는 도전 과제와, 개념을 확인하는
자가 점검 문제로 구성된다.

> ⚠️ 모든 문제는 **본인 소유 시스템, 지정된 실습 랩, 또는 명시적으로 인가된
> 공개 플랫폼(HTB, THM, PortSwigger, Juice Shop 등)**에서만 수행한다.
> 실제 서비스·타인 시스템 대상 실습은 [윤리와 법률](/docs/getting-started/ethics-legal/) 위반이다.

## 난이도 표기 {#difficulty}

| 표기 | 의미 |
|---|---|
| 🟢 입문 | 개념 확인, 단일 기법 |
| 🟡 중급 | 여러 단계 연결 |
| 🔴 실전 | 정찰→익스플로잇→포스트까지 풀 체인 |

각 문제는 **목표 → 힌트(펼치기) → 해설(펼치기)** 순서다. 힌트를 보기 전에
스스로 충분히 시도한다.
